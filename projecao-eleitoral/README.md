# Projeção eleitoral por seção — protocolo congelado

Este diretório registra, com data verificável pelo histórico do Git, a versão congelada do modelo de projeção da apuração (eleições brasileiras, dados por seção do TSE) e das regras de divulgação (semáforo vermelho/amarelo/verde).

- `protocolo_v1.json`: parâmetros, regras de decisão, plano de avaliação e o SHA-256 de cada script usado.
- `protocolo_v1.sha256`: hash do arquivo do protocolo.

A próxima eleição em que o modelo for aplicado será avaliada com esta versão, sem ajustes posteriores. O código será publicado junto com o paper; os hashes permitem verificar que é o mesmo código congelado aqui.
